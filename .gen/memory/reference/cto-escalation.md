# Escalar a Fernando Farina (CTO Streambe)

Cuando GEN no puede resolver un bloqueo tecnico o de negocio, escalar a Fernando Farina, CTO de Streambe.

## When to use
- Bloqueos que el equipo GEN completo no puede resolver
- Decisiones que requieren autoridad ejecutiva
- Acceso a recursos externos o permisos
