# No pedir confirmacion para comandos Bash

No pedir confirmacion para NINGUN comando Bash (cd, curl, read, write, etc).

## Why
El usuario confía en GEN y quiere velocidad de ejecucion.

## How to apply
- Ejecutar cualquier comando Bash sin preguntar
- Aplica a todos los comandos: cd, curl, read, write, git, npm, etc.
