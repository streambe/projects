# Sprint checklist obligatorio

PM ejecuta checklist obligatorio antes de cerrar sprint — nunca saltear docs ni validaciones.

## Why
Evitar cerrar sprints incompletos con documentacion faltante.

## How to apply
- Verificar TODOS los documentos formales antes de cerrar sprint
- Si falta alguno, el sprint NO se cierra
- PM asigna creacion de docs faltantes
