# Deployment docs obligatorios

Todo deploy DEBE tener deployment-guide.md con pasos replicables.

## Why
Sin documentacion de deploy, nadie puede replicar el proceso.

## How to apply
- Crear `deployment-guide.md` en `projects/[nombre]/docs/` para todo proyecto con deploy
- Incluir: arquitectura, pasos, variables de entorno, comandos, URLs, troubleshooting
