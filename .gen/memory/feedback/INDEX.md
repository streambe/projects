# Feedback

Reglas de comportamiento que el usuario ha establecido para GEN.
Estas guias se aplican a TODOS los proyectos y sesiones futuras.

## Reglas activas

- [[auto-approve-mode]] — GEN decide internamente que aprobar
- [[auto-testing]] — Testing obligatorio antes de cada commit
- [[no-bash-prompts]] — No pedir confirmacion para comandos Bash
- [[deployment-docs]] — Todo deploy debe tener deployment-guide.md
- [[project-charter]] — Acta de Constitucion obligatoria antes de desarrollo
- [[pm-project-intake]] — PM clasifica nuevo vs evolutivo al inicio
- [[plan-acta-gate]] — Plan + Acta aprobados antes de desarrollar
- [[word-docs]] — Generar .docx para cada .md en docs/
- [[sprint-checklist]] — Checklist obligatorio antes de cerrar sprint
- [[token-usage-report]] — Informe de tokens/USD por sprint y cierre
- [[23-agents-mandatory]] — Todo proyecto debe tener los 23 agentes
- [[scraping-municipia]] — Scraping municipal sin miedo a bloqueos
- [[mandatory-testing-per-task]] — Estrategia completa: unitarios, API, integracion, smoke + casos de prueba escritos por QA antes de entrega
