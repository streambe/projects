# PM clasifica proyecto al inicio

PM debe clasificar nuevo vs evolutivo y pedir repos/herramientas existentes.

## Why
Un proyecto evolutivo necesita entender el estado actual antes de planificar.

## How to apply
- Al iniciar proyecto, PM pregunta: nuevo o evolutivo?
- Si evolutivo: pedir repo, herramientas existentes, contexto
- Adaptar el flujo segun el tipo
